# Ocupación de aparcamientos públicos municipales de Málaga

Copia automática (cada hora) del dataset abierto del Ayuntamiento de Málaga:
https://datosabiertos.malaga.eu/recursos/aparcamientos/ocupappublicosmun/ocupappublicosmun.csv

- `data/ocupacion_actual.csv` → última descarga
- `data/historico/AAAA-MM-DD/AAAA-MM-DD_HHMM.csv` → todas las descargas

Pensado para usarse desde Databricks Free Edition (que no permite acceder a la URL original) mediante un Git folder.
